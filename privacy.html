Privacy Policy

Last updated: 2026-10-21

Qamar Stories is made for parents to read with their children. It has no accounts, no forms, no comments and no analytics. It does not set cookies, does not use browser storage, and does not load third-party scripts, fonts or images. It does not ask for names or any other personal information, and we do not knowingly collect personal information from children.

The language you choose on a story (English, Arabic or both) is kept only in the page address (for example #ar). It is not stored or sent to us.

Hosting. The site is hosted on GitHub Pages. GitHub may log visitors' IP addresses for security and operation. See GitHub's privacy statement.

Ads and affiliate links. There are no ads or affiliate links today. If we add them later, we will update this page first and label affiliate links clearly.
